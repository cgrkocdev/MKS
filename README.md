# MKS Ön Muhasebe

Kasa giriş, kasa çıkış ve ödeme planlama modüllerine sahip Next.js uygulaması.

## Çalıştırma

Node.js 20 veya üzeri kurulduktan sonra:

```bash
npm install
npm run dev
```

Ardından `http://localhost:3000` adresini açın.

## Özellikler

- Genel kasa özeti ve son hareketler
- Gelir/gider kaydı ekleme, arama ve silme
- TRY, USD ve EUR para birimleri
- Ödeme planı oluşturma ve ödemeyi kasa çıkışına aktarma
- Tarayıcıda kalıcı veri saklama
- Mobil ve masaüstü uyumlu arayüz
